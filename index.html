IPAD WORKSPACE

在 iPad 上打开

网站已经适配 iPad 的横屏、竖屏和触控操作。临时使用时让电脑与 iPad 连接同一个 Wi‑Fi；长期离线使用则需把网站部署到 HTTPS 地址后添加到主屏幕。

01

同一 Wi‑Fi 临时使用

  1. 在电脑上运行项目目录中的 start-ipad.ps1。
  2. 如果 Windows 防火墙询问，请允许专用网络访问。
  3. 在 iPad Safari 中打开脚本显示的局域网地址，例如 http://192.168.1.8:8080。

这种方式适合日常学习和批注。个人新增文献保存在 iPad Safari 中，停止电脑服务器后页面需要重新服务。

02

主屏幕与离线模式

  1. 把整个项目文件夹部署到 GitHub Pages、Cloudflare Pages 或其他 HTTPS 静态托管。
  2. 在 iPad Safari 打开部署地址，等待页面完整加载一次。
  3. 点击 Safari 的“分享”，选择“添加到主屏幕”。

网站已包含离线缓存。HTTPS 部署后可从主屏幕独立打开，并在断网时继续浏览种子文献。

同步电脑上的个人文献

先在电脑点击“导入 / 导出 → 导出个人数据”，把 JSON 文件通过隔空投送或 iCloud 发送到 iPad；再在 iPad 的网站中导入。
